## 3 判定

- 確かめ用の5つで、今の形より高かった数（と、差の平均）：GZ：下落 30% で 0 1 / 5（-2.3%）、GZ：下落 40% で 0 1 / 5（-1.3%）、GZ：下落 50% で 0 1 / 5（-0.9%）、REDD（直近250日）：下落 30% で 0 1 / 5（-0.8%）、REDD：下落 40% で 0 1 / 5（-0.6%）
- 確かめ用の5つでいちばん良い形：**REDD：下落 40% で 0**
- (a) 金で、その形が今の形より高い（全期間・前半・後半）：○（+4.6% 対 +4.4%、+4.7% 対 +4.4%、+9.3% 対 +8.9%）
- (b) 確かめ用の5つのうち4つ以上：×（1 / 5）
- 判定：不合格
